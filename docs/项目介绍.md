# NFC智能门禁系统 - 项目介绍

## 一、项目概述

本项目是一个基于ESP32微控制器开发的智能门禁控制系统。系统采用PN532 NFC模块实现非接触式身份识别，结合继电器控制电磁锁，并通过门磁传感器实现开门后自动上锁功能。

系统适用于家庭、办公室、实验室、小型商铺等需要安全门禁控制的场景。

---

## 二、核心技术

### 2.1 硬件平台
- **主控芯片**：ESP32 DevKit V1（双核、内置WiFi和蓝牙）
- **NFC模块**：PN532（支持ISO14443A标准，HSU/UART通信模式）
- **执行机构**：光耦隔离继电器模块 + 电磁锁
- **传感器**：干簧管门磁传感器（检测门开关状态）
- **输入设备**：6x6x5微动按钮（内部物理开门按键）

### 2.2 通信协议
- NFC模块与ESP32采用**HSU（Host Standalone Mode）**模式通过UART串口通信
- 支持读取MIFARE系列卡片UID（4字节/7字节）

### 2.3 开发框架
- PlatformIO（跨平台嵌入式开发环境）
- Arduino框架（ESP32）
- GitHub Actions（CI/CD自动构建）

## 三、系统功能

### 3.1 身份认证
- 支持多张授权NFC卡片
- 刷卡后自动验证卡片UID是否在授权列表中
- 未授权卡片将被拒绝访问
- NFC读取冷却时间：2秒（防止重复刷卡）

### 3.2 开锁控制
- **NFC开门**：授权卡片靠近即可自动开锁
- **按钮开门**：内部物理按钮支持一键开门
- **安全超时**：解锁状态持续10秒后自动重新上锁（防止长时间保持开锁）

### 3.3 自动上锁
- 开锁后监测门磁传感器状态
- 门关闭并保持2秒后，自动执行上锁操作
- 门磁传感器消抖处理（100ms），防止误触发

### 3.4 状态机管理
系统采用有限状态机（FSM）管理门锁状态，状态包括：
- `Idle`（空闲/已上锁）
- `Unlocked`（已开锁）
- `DoorOpened`（门已打开）
- `DoorClosedConfirm`（门已关闭，等待确认）
- `Locking`（执行上锁）

## 四、技术亮点

1. **模块化设计**：硬件抽象层与业务逻辑分离，便于维护和扩展
2. **状态机控制**：采用严格的状态机管理，确保系统行为可控
3. **消抖处理**：按钮和门磁传感器均配备软件消抖，提高可靠性
4. **安全机制**：10秒自动超时上锁，防止意外长时间开锁
5. **实时日志**：串口输出详细运行日志，便于调试和故障诊断
6. **CI/CD集成**：GitHub Actions实现代码提交自动构建验证

## 五、项目架构

│   ├── hardware/             # 硬件抽象层
│   │   ├── relay.cpp/h       # 继电器控制模块
│   │   ├── button.cpp/h      # 按钮检测模块
│   │   ├── door_sensor.cpp/h # 门磁传感器模块
│   │   ├── nfc.cpp/h         # NFC读卡模块

## 六、应用场景

- 🏠 **家庭门禁**：取代传统钥匙，NFC卡片开门更方便安全
- 🏢 **办公室管理**：控制员工进出权限，支持多卡片授权
- 🔬 **实验室安全**：限制非授权人员进入敏感区域
- 🏪 **商铺门锁**：小型店铺的智能门禁解决方案
